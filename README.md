# My First Portfolio Website

The first draft of my personal portfolio website, created while learning the fundamentals of front-end web development.

This project served as an introduction to building personal websites using HTML, CSS, and JavaScript. It was designed to showcase basic information about myself, my projects, technical skills, and contact details while providing hands-on experience with responsive layouts, styling, and client-side interactivity.

---

## Overview

This portfolio website was developed as a learning project to understand how modern websites are structured and styled.

The project focuses on:

* Website layout design
* Personal branding
* Responsive web development
* Front-end fundamentals
* User interface design
* JavaScript-based interactions

---

### Personal Introduction
